# Seasonal Reference Still — Edit Prompts

Twenty-one image-to-image edits: all seven locations in winter, spring, and autumn
(summer is the canonical itself). Each one **edits the canonical photo**, changing
only the season — this is what keeps the geography from drifting. Paste into your
image tool's **edit / image-to-image** mode with the named canonical attached.

DO use an edit / image-to-image mode (the canonical is the input).
DON'T type these into a blank text-to-image box — that loses the geometry, the same
way the first Beaver Meadow clip drifted to open marsh.

After each edit, save with the exact filename shown, into
`90 media/Photograph/reference-stills/`. That still then becomes the first frame for
the matching Veo clip (`reference-BM-winter-001.png` → `BM-winter-001.mp4`).

Every prompt shares this spine, with the location's invariant and the season filled in:

> Image-to-image edit of the attached canonical photograph. Preserve EXACTLY: the
> viewpoint, composition, framing, landform, the position of every feature, and the
> scale. **[invariant]**. Change ONLY the season. **[seasonal character]**. Natural
> light plausible for the season. Do not move, add, or remove landforms; do not open
> up or enclose the space differently; do not restyle, beautify, or add drama.
