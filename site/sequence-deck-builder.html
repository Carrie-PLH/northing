How to use the Sequence Deck Builder

A quiet table for arranging Northing material as cards. It is for exploring relationships between places, artifacts, photographs, observations, and conditions while developing sequences. It is not a video editor and is not meant to replace one. Everything stays on this computer (stored locally in your browser); nothing is uploaded.

1 · Cards and the library

The left rail is your card library — every card you create or import lives here. Make one with the New card chips at the top (Landscape Clip, Artifact, Photograph, Observation, Environmental Mood State, Soundscape). Each type has its own fields. Click a library card's ✎ to edit it, ＋ to add it to the board, or ✕ to delete it. Use the search box to filter by title or location.

2 · Building a sequence

The centre is the board — the cards you've placed, in order, numbered as a sequence. Drag a card from the library onto the board to add it; a guide line shows where it will land. Drag cards already on the board to reorder them. The same library card can appear more than once (a place you return to). Each board card has ✎ to edit and ✕ to remove it from the sequence (it stays in the library). Rename the sequence in the top bar.

Grouping: click cards to select them (Shift- or Cmd-click for several), then Group selected to bracket them under a name, or Ungroup to release them. Clear board empties the sequence without touching the library.

Prompting shots: each board card's ▶ opens the Clip Prompt Generator in a new tab, pre-filled from that card (location, season, conditions, notes). To compose a shot spec from several cards — say a canonical location plus an environmental mood state — select them and use Prompt selected: location and conditions come from the first card that has them, and mood states and observation context fold into the prompt notes. Generated keepers come back in through Import Media Folder as real clips.

3 · Templates

Templates drops a starter sequence of placeholder cards onto the board (Static Encounter, Reverse Echo, Landscape Echo, Observer Chain, Environmental Trigger, Unread Document). Edit the placeholders in place, or swap in real library cards.

4 · Relationships

The toggle chips in the board bar (same location, season, observer, condition) draw faint connecting lines between related cards, so repetitions and echoes surface on their own. Hovering a card dims the unrelated ones. These are display aids only.

Connections (header button) goes further: it scans the whole library for structural affinities — return-to-place, shared rare details, the same water upstream and down, co-visibility from the ridge, mood states matched to sites that produce them, shared periods — and suggests combinations. Tight combos are near-ready shot specs; larger constellations (up to 20 cards, placed as a named group) are fields for whittling: delete what doesn't read true, select the survivors, Prompt selected. If cards are selected on the board when you open it, suggestions bias toward them. More reshuffles.

5 · Analysis panel

The right panel continuously reads the current sequence: card count, total duration, artifact/landscape/photo counts, and location and seasonal diversity, plus a composition bar by card type. The metrics framework is built to be extended later (return-to-place frequency, archive density, and so on are scaffolded, not yet computed).

6 · Orientation internal · approximate · not for decks

The Orientation button opens the internal spatial layer. It uses an approximate internal map of the watershed to keep sequences geographically coherent. It is internal and approximate — not public canon, and it should never appear in audience-facing decks. Location canon is authoritative; the map only constrains ordering, it does not generate narration.

Pick a geographic sequence mode (Watershed, Eastern tributary, Elevation descent, Viewshed-to-ground, Hidden drainage, Bench-to-valley) to lay down a coherent spine, drawing on matching library cards or light placeholders. The Spatial coherence block in the analysis panel reads your current sequence and tags each transition (descends/ascends, with/against drainage, adjacency, RO viewshed) — again, internal and approximate.

7 · Importing a media folder

Import Media Folder scans a folder you choose for images and video, and proposes a card for each file, inferring type, location, and title from the folder and filename. Review the proposals — adjust type, title, location, and which to include — then add them to the library. Files are never uploaded; only thumbnails and metadata are stored locally.

8 · Exporting

Export Sequence offers three tabs. Markdown outline and JSON are audience-facing and contain no internal map data. Internal notes is opt-in and carries the spatial annotations with their approximate/internal disclaimer — keep it out of finished decks. Copy or download from any tab.

Library lets you export the whole card library as JSON to back it up or move it to another machine, and import it back later without rescanning. Sync artifact catalog pulls the live online catalog and creates or updates one Artifact card per entry (re-sync updates, never duplicates); the catalog remains the single place artifacts are maintained. Per the project rule, photographs are treated as artifacts — both catalog entries and imported images become Artifact cards.

Storage

Cards, sequence, and settings are saved in this browser (IndexedDB) — but browsers treat storage for local pages as disposable and may clear it on quit. The durable option: Library → Connect library file. Pick your library JSON once per session and every change auto-saves to it; after a reboot, connecting again restores cards, sequence, and name from the file. The file is the store; the browser is just a cache. Export remains available for one-off snapshots.

Connections · suggested combinations

Structural affinities found across the library — the same place under different conditions, a shared detail, the same water upstream and down, a state meeting ground that produces it. Tight combos are near-ready shot specs; constellations are larger fields meant for whittling: place one, delete what doesn't read true, then select the survivors and use Prompt selected. Suggestions, not assertions.
