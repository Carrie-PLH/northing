How to use the Sequence Deck Builder

Start here — the big picture

Making a Northing video has two separate steps, done with two different tools. Getting them straight is the whole game:

Step 1 — make the clips (in Veo). Veo is the only thing that creates new footage: short 4-to-8-second pieces, one at a time, in your web browser. That's it for Veo. You feed it a canonical image and a prompt, it hands you a clip, you save the keepers.

Step 2 — glue the clips together (this tool + one Terminal command). This deck builder is a table where you lay out cards — clips, photos, sounds — in the order you want them. It makes no footage of its own. When the order looks right, you Export the board and run one command (assemble.py, which uses a stitching tool called ffmpeg) that combines everything into one finished video. No AI in this step — it's just gluing pieces you already have.

So: Veo cooks the ingredients, this tool plates the meal. Both are still in use; they just happen at different moments. If you only remember one thing: new footage = Veo; finished video = this tool plus the assemble command. The numbered sections below are reference for when you need a specific detail — you don't need to read them to use the tool.

Quick command reference

Everything runs in the Mac Terminal (Cmd+Space, type Terminal, Enter), one line at a time. Start every session by going to the project folder:

Make new clips (Veo runner — reads your *clip-prompts.md files)

Tag the media (once after adding clips or artifacts — writes the facet index the generator and audio use)

python3 scripts/facet-index.py tag artifacts (reads the images in 90 media/artifact/): python3 scripts/facet-index.py --artifacts cheaper run: add --model claude-haiku-4-5-20251001

Build an hour automatically (the long-form generator)

python3 scripts/shuffle-board.py --minutes 60

It prints a render: line with the exact next command and the real filename. Paste that line to render. Repeat a run you liked with --seed NNNN; one season only with --season winter. Pick a production register with --preset: field (documentary, the default), wander (looser, still place-based), or drift (one associative stream); on drift add --recurrence refrain to let a shot return or --transitions mixed for flash frames and hard cuts, on field/wander add --weather coherent for one condition per chapter. No Terminal at all: set these in the deck builder's Commands screen and click Generate to project, then double-click Generate to project in your Northing folder.

Build a composed piece by hand (this tool)

Check a board's sound (flags any bed that fights its season — e.g. rain over snow)

A quiet table for arranging Northing material as cards — places, artifacts, photographs, observations, conditions — and, together with scripts/assemble.py, the project's video editor: a board exported as JSON renders directly into a finished video (see section 9). It is an editor with deliberately little freedom — no timeline, no trimming, no grading; three fixed transitions and a position rule for sound. The order of cards is the entire edit, and the register is enforced by what the tool declines to offer. Everything stays on this computer (stored locally in your browser); nothing is uploaded.

1 · Cards and the library

The left rail is your card library — every card you create or import lives here. Make one with the New card chips at the top (Landscape Clip, Artifact, Photograph, Observation, Environmental Mood State, Soundscape, Transition). Each type has its own fields. Click a library card's ✎ to edit it, ＋ to add it to the board, or ✕ to delete it. Use the search box to filter by title or location.

Transition cards are mechanical artifacts of the medium, not editorial gestures, and there are deliberately only three: Black gap (0.5s of unexposed black — the camera was off between shots; use it wherever a hard cut feels abrupt, especially across different ground), Flash frame (two frames of exposure burn — the camera restarting; suits a return to the same ground in a different register), and Fade through black (0.8s fade down, a held breath of black, 0.8s fade up — lab-print practice, the slow option for chapter-scale joins). Durations are fixed in the assembler, not on the card. Crossfades between images are deliberately unsupported — that is an editor's gesture, and the register forbids it.

2 · Building a sequence

The centre is the board — the cards you've placed, in order, numbered as a sequence. Drag a card from the library onto the board to add it; a guide line shows where it will land. Drag cards already on the board to reorder them. The same library card can appear more than once (a place you return to). Each board card has ✎ to edit and ✕ to remove it from the sequence (it stays in the library). Rename the sequence in the top bar.

Card order is meaning. A soundscape card governs the audio from its position until the next soundscape card — so a board that opens with a soundscape puts everything under that audio; a soundscape placed mid-board starts there. Cards before any soundscape keep their native clip audio (stills are silent there). To have one soundscape span the whole sequence, place it first. Mood and observation cards are compositional guidance — they shape prompts and reading, but render no picture.

Grouping: click cards to select them (Shift- or Cmd-click for several), then Group selected to bracket them under a name, or Ungroup to release them. Clear board empties the sequence without touching the library.

Prompting shots: each board card's ▶ opens the Clip Prompt Generator in a new tab, pre-filled from that card (location, season, conditions, notes). To compose a shot spec from several cards — say a canonical location plus an environmental mood state — select them and use Prompt selected: location and conditions come from the first card that has them, and mood states and observation context fold into the prompt notes. Generated keepers come back in through Import Media Folder as real clips.

3 · Templates

Templates drops a starter sequence of placeholder cards onto the board (Static Encounter, Reverse Echo, Landscape Echo, Observer Chain, Environmental Trigger, Unread Document). Edit the placeholders in place, or swap in real library cards.

4 · Relationships

The toggle chips in the board bar (same location, season, observer, condition) draw faint connecting lines between related cards, so repetitions and echoes surface on their own. Hovering a card dims the unrelated ones. These are display aids only.

Connections (header button) goes further: it scans the whole library for structural affinities — return-to-place, shared rare details, the same water upstream and down, co-visibility from the ridge, mood states matched to sites that produce them, shared periods — and suggests combinations. Tight combos are near-ready shot specs; larger constellations (up to 20 cards, placed as a named group) are fields for whittling: delete what doesn't read true, select the survivors, Prompt selected. If cards are selected on the board when you open it, suggestions bias toward them. More reshuffles.

Two-card visual combos now arrive with the mechanically apt transition between them: different ground gets a black gap (the camera was off in between), the same ground in a different register gets a flash frame (the camera restarted). The transition cards are created in your library on first use and reused after. They are joins, never content — Connections will not suggest them as material. Delete the join if the cut should be hard.

5 · Analysis panel

The right panel continuously reads the current sequence: card count, total duration, artifact/landscape/photo counts, and location and seasonal diversity, plus a composition bar by card type. The metrics framework is built to be extended later (return-to-place frequency, archive density, and so on are scaffolded, not yet computed).

6 · Orientation internal · approximate · not for decks

The Orientation button opens the internal spatial layer. It uses an approximate internal map of the watershed to keep sequences geographically coherent. It is internal and approximate — not public canon, and it should never appear in audience-facing decks. Location canon is authoritative; the map only constrains ordering, it does not generate narration.

Pick a geographic sequence mode (Watershed, Eastern tributary, Elevation descent, Viewshed-to-ground, Hidden drainage, Bench-to-valley) to lay down a coherent spine, drawing on matching library cards or light placeholders. The Spatial coherence block in the analysis panel reads your current sequence and tags each transition (descends/ascends, with/against drainage, adjacency, RO viewshed) — again, internal and approximate.

7 · Importing a media folder

Import Media Folder scans a folder you choose for images and video, and proposes a card for each file, inferring type, location, and title from the folder and filename. Review the proposals — adjust type, title, location, and which to include — then add them to the library. Files are never uploaded; only thumbnails and metadata are stored locally.

Clips arrive with their prompt attached. When you import 90 media/Landscape Clip (pick the whole folder, not a single location, so the clip-manifest.json beside the clips is found), each clip card is filled in from the manifest — its heading and full prompt text fold into the card's notes, which is what lets it surface in Connections. A clip already in the library is enriched in place rather than skipped, so re-importing after generating more clips tops up the thin early cards. A clip marked ✓ prompt attached from manifest in the review panel matched the manifest.

Artifacts live on disk now, like everything else. They sit in 90 media/artifact/<LOC>/ in the same per-location structure as clips, and you import them the same way — point Import Media Folder at that folder and the images come in as Artifact cards with their location inferred. are.na is your upstream library for collecting and thinking; the pipeline reads the disk copies, so nothing depends on a live link at render time.

8 · Exporting

Save this board (toolbar) is the simplest way to hand the sequence you've arranged on the table to the renderer: it writes that exact board into 90 media/boards/, overwriting, so the double-click Render latest board always finds your current version. Use it for boards you compose by hand. It only ever saves what's on the table — it has nothing to do with the generator; for a board built by the generator from a preset, use Generate to project in the Commands screen instead (section 9). Together: Save this board = the board on screen; Generate to project = a fresh board from settings. Export Sequence is the portable alternative and offers three tabs: Markdown outline and JSON are audience-facing and contain no internal map data, and Internal notes is opt-in and carries the spatial annotations with their approximate/internal disclaimer — keep it out of finished decks. Copy or download from any tab. The JSON tab is the one the assembler eats — name the sequence in the top bar first, because the finished video and the saved file both inherit the name.

Library lets you export the whole card library as JSON to back it up or move it to another machine, and import it back later without rescanning. Per the project rule, photographs are treated as artifacts — imported images become Artifact cards. Sync artifact catalog (the old are.na pull) is legacy now that artifacts live on disk under 90 media/artifact/ and import like clips; it still works for older boards but new work should import from the disk folder.

9 · From board to finished video — the production pipeline

The full loop, end to end: Connections suggests combinations → Prompt selected fills the Clip Prompt Generator → Veo renders candidate clips (conditioned on a canonical or reference image — style language in prompts is inert, the reference image is the art direction) → keepers land in their location folder under 90 media/Landscape Clip/ and come back in through Import Media Folder → scripts/facet-index.py tags every clip and artifact so the tools know what each one shows → a board, made by hand in this tool or generated by scripts/shuffle-board.py, goes to scripts/assemble.py, which renders one finished video into 90 media/assembled clip/. scripts/treat.sh can age the clips first; the renderer prefers treated versions automatically.

Keeping the index current. The generator, the audio matcher, and the linter all read two indexes built from your material, so keep them fresh: whenever you add clips or artifacts, re-tag with python3 scripts/facet-index.py (and python3 scripts/facet-index.py --artifacts for new artifacts); whenever you add soundscapes, re-run python3 scripts/audio-match.py --scan. Both are incremental — they only touch what's new and keep existing tags — and both are one click away in the Commands panel. Skipping them doesn't break a render, but new clips will sit untagged (invisible to the season, arc, and thread logic) and new beds won't be considered until scanned.

Run it. Two no-Terminal paths, and which you want depends only on where the board comes from. Save this board sends the sequence you arranged on the table here — it saves exactly what's on screen. Generate to project ignores the table and has the generator build a fresh board from the options you pick (preset, season, axes, thread). Each then pairs with its own double-click that renders the result. The manual Terminal path below is for when you want extra control over resolution or fades.

The easy path for a hand-built board — no Terminal. Make your edits, then click Save this board in the toolbar. The first time it asks for your Northing folder and then remembers it; it writes the board into 90 media/boards/, always overwriting, so there's no Downloads copy and no stale version. Then double-click Render latest board (the .command file in your Northing folder — keep a copy on the Desktop if you like). It first runs the board linter and, if the board is sound, renders it at 1920×1080 and opens the assembled-clip folder when it finishes. If the linter finds a render-breaking problem (a missing file, a card still pointing at a web link) it stops and tells you what to fix rather than producing a broken video; coherence warnings print but don't stop the render. So: edit, Save this board, double-click. No file names, no cd, nothing to mistype. The Save button needs Chrome or Edge.
The easy path for a generated hour — no Terminal. When you'd rather the generator build the board, open Commands and set your options under Generate an hour automatically — minutes, preset (Field / Wander / Drift), one season only, the weather coherent, let images return, or harder joins checkbox, Season-order and Arc overrides, an optional affinity thread. Then click Generate to project: it saves those settings into the project (same one-time folder permission as Save this board). Double-click Generate to project (the .command in your Northing folder) and it builds the board with exactly those options, lints it, and renders it at 1920×1080 straight through, opening the assembled-clip folder when done. It's the generator's version of Save this board → Render, collapsed into one click and one double-click, so you never paste a command or choose a seed by hand. Like Save this board, it needs Chrome or Edge.

The manual path — exact Terminal steps. Use this when you want to set resolution or fades, or to generate an hour. Commands are for the Mac Terminal app (Cmd+Space, type Terminal, Enter). Paste one line at a time, pressing Enter after each.

Reading the receipt. The render prints what it used and what it skipped. Skipped mood and observation cards are correct — they're guidance, not picture. An artifact or clip that says media not found: with a path after the colon means that file isn't where the board expects it; if the board predates the move to disk artifacts, its artifact cards may still point at old catalog paths and need repointing to 90 media/artifact/.

treat.sh — run bare (treat.sh clip.mp4) it applies the locked house default: medium intensity plus exposure flicker. Output goes to a treated/ subfolder beside the untouched raw; it never modifies keepers and is idempotent, so the whole corpus can be re-treated in one pass if the preset evolves. --batch treats a folder; heavier tiers (--intensity heavy/xheavy) are deliberate register choices for implied-older material, not defaults.

assemble.py — reads the exported JSON and renders the board in order: clips play (preferring their treated/ sibling automatically), image cards hold for 5 seconds as living stills — house grain and flicker plus a slow, seeded drift (a barely conscious push or pull with slight pan, always the same move for the same file) so they read as filmed inserts, never freeze-frames. Every clip and still eases up from and down to black at its edges (default 0.6s), so cuts read as gentle breaths rather than quick blinks; pass --clip-fade 0.9 or 1.2 for slower fades, --clip-fade 0 for hard cuts. Soundscapes follow the position rule in section 2, looping or trimming to their region with edge fades, and every audio region is mastered to the same perceived loudness (−20 LUFS house target). Transition cards render at their fixed durations; a governing soundscape runs through black unbroken. Naming and filing: with no --out, the finished video is named for the places it visits, in order, each chapter as CODE-season-condition (e.g. TC-autumn-rain-BM-winter-001), and written to 90 media/assembled clip/; a season or condition is left out when the footage doesn't clearly carry it. Output is 720p/24 by default; pass --width 1920 --height 1080 for channel-resolution renders.

shuffle-board.py — the long-form generator, for the ambience-channel goal of hour-long videos that re-edit the same material in fresh orders. It scans the media pool, reads the facet index, and writes an assembler-ready board of any length, structured as location chapters. A production register sets how coherent the edit is. --preset field (the default) is the documentary mode described in the rest of this paragraph, and reproduces a given --seed exactly. --preset wander keeps the location chapters but unshackles the season order and softens the arc, for a looser ramble. --preset drift dissolves the chapters into one continuous associative stream that moves by what successive clips physically share — subject, water state, condition — rather than by place, under a single neutral water bed chosen once; on drift, --recurrence refrain lets a recent shot return as a sparse, irregular echo and --transitions mixed mixes flash frames and hard cuts into the black gaps for a more disjunctive stream. Single axes can also be set on their own: --weather coherent holds each chapter to one condition (a stricter-realism Field/Wander cut), and --season-mode / --arc override a preset's defaults. All of this is exposed in the deck builder's Commands screen, with Generate to project for a no-Terminal build-and-render. Everything below describes the Field/Wander (location-chapter) behaviour; Drift replaces the chapter machinery with the associative stream but draws on the same clips, facets, and neutral beds. Each chapter follows a soft arc — it establishes the place on a wide, settles into closer detail through the middle, then withdraws to quieter wide or immersive shots before the fade — built from visits, a clip dwelled on for two or three takes with black gaps between, artifact stills folded in after the place is established, the canonical still landing in the settle as a resting image, with fades through black at chapter boundaries. The arc is a preference, never forced: a location that only carries one kind of shot this season simply reads in that register rather than having a shape imposed on it. Seasons are coherent by default: each chapter takes one season and the year runs forward across the video (spring into summer into autumn into winter and round again), so no chapter mixes seasons; --season winter instead pins the whole video to one season. Sound is matched, not guessed: each chapter's bed is chosen for that location and season through the same guard as audio-match.py, so a winter chapter never plays under rain and warm-season frog or insect beds stay out of autumn and winter. Long chapters split their sound: when a chapter runs several minutes and its best-fitting bed is short enough to loop audibly, the generator lays a second, distinct, still-compatible bed across the back half — a quiet audio shift inside the same place, never a location change, so no short bed repeats itself; --max-beds 1 keeps a single bed per chapter. An optional affinity thread — --thread condition:fog, --thread water_state:frozen, --thread trace:beaver — lays a quiet recurrence along one facet so it reappears across the hour without being announced: it never adds visits or pulls in off-location material, only nudges which clip or still a visit already about to happen reaches for, and only where the place actually carries it. It reads best on a facet that turns up in several locations but dominates none. Every run shuffles differently; --seed NNNN reproduces one you liked. Typical use: python3 scripts/shuffle-board.py --minutes 60, then paste the render: line it prints (an hour renders in very roughly half an hour to forty-five minutes). The generator never changes the assembler — it just writes boards, so everything above applies.

qc-render.py — the check before upload, for the hour renders nobody watches end to end. It scans a finished video and prints a timestamped report: black intervals beyond the house transitions, audio dropouts (a governing soundscape runs through transitions, so mid-file silence is always a fault), and level anomalies against the −20 LUFS target. python3 scripts/qc-render.py final.mp4 --report writes the report beside the file; exit code 0 means clean. Housekeeping cousin: sync-canonical.sh --check verifies the site's canonical-image copy still matches the master set in 90 media/Photograph/A-CANONICAL-IMAGES/.

The deck builder remains the place where composed sequences are made — the shuffle generator handles bulk hours; this table handles the ones that are meant.

lint-board.py — the whole-board check before a render. python3 scripts/lint-board.py board.json walks the board and reports, by chapter: pictures and artifacts that don't resolve to a real file or still point at a web link, soundscapes that fail the season guard, artifacts sitting in the wrong location's chapter, chapters that don't open on a wide when their location has one, and clips from the wrong season. [x] marks render-breaking faults (it exits non-zero, which is how the double-click render knows to stop); [!] marks coherence notes that print but don't block, unless you pass --strict. It shares the audio guard with audio-match.py, so the two never disagree; audio-match.py --board remains the audio-only deep dive when you want suggested beds, not just pass/fail.

Storage

Cards, sequence, and settings are saved in this browser (IndexedDB) — but browsers treat storage for local pages as disposable and may clear it on quit. The durable option: Library → Connect library file. Pick your library JSON once per session and every change auto-saves to it; after a reboot, connecting again restores cards, sequence, and name from the file. The file is the store; the browser is just a cache. Export remains available for one-off snapshots.
